Two files in this distribution are DERIVED from IEC code components:

    src/py61850/scl/_content_models.py

Neither code component is itself part of this distribution, and each derived
file takes one narrow dimension of the component it came from.


1. src/py61850/scl/_content_models.py
-------------------------------------

It carries the SCL content models -- which child elements each SCL element may
hold, and the order they go in -- extracted from the SCL XML schema published
by IEC as a code component of IEC 61850-6. The schema itself is NOT part of
this distribution. What is derived from it is one structural dimension: element
names and their order, and none of the schema's attributes, types,
enumerations, cardinalities, uniqueness constraints or documentation.

2. src/py61850/scl/_nsd_types.py
--------------------------------

It carries two facts about the IEC 61850 data model -- which common data class
each data object name has, and which basic type each of a class's data
attributes has -- extracted from the namespace definitions published by IEC as
code components of IEC 61850-7-4 and IEC 61850-7-3. The namespace definitions
themselves are NOT part of this distribution. What is derived from them is the
type dimension alone, and none of their functional constraints, presence
conditions, enumerations and their literals, abbreviations, service parameters,
UML identifiers or documentation.

Attribution, as the licence below requires:

    This code was derived from IEC 61850-7-3:2010 and IEC 61850-7-4:2020 within
    modifications permitted in the relevant IEC standard. Please reproduce this
    note if possible.

The code components it was derived from:

    IEC 61850-7-3 namespace definition V2007B5
    Code component id: IEC 61850-7-3:2007B5
    Publication: IEC 61850-7-3:2010 (Ed. 2.1), dated 2024-02-12

    IEC 61850-7-4 namespace definition V2007B5
    Code component id: IEC 61850-7-4:2007B5
    Publication: IEC 61850-7-4:2020 (Ed. 2.1), dated 2024-02-14
